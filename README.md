# Todo App (Next.js + Neon Postgres)

## اجرای محلی
1. `npm install`
2. فایل `.env.example` را به `.env.local` کپی و مقادیر را پر کنید
3. `npm run dev`  ← http://localhost:3000

## دیپلوی روی Vercel
1. پروژه را روی GitHub بگذارید
2. در Vercel: Add New → Project → ریپو را انتخاب کنید
3. در تب Storage یک دیتابیس Neon (Postgres) بسازید و به پروژه وصل کنید (متغیر `DATABASE_URL` خودکار اضافه می‌شود؛ اگر اسم دیگری داشت، همین نام را بسازید)
4. در Settings → Environment Variables مقدار `APP_PASSWORD` را بگذارید
5. Deploy بزنید. جدول در اولین بازدید خودکار ساخته می‌شود.

## امکانات
- افزودن/ویرایش/حذف، اولویت (بالا/متوسط/پایین)، دسته‌بندی، موعد انجام
- فیلتر: وضعیت، عنوان، دسته، اولویت، بازهٔ تاریخ (ثبت / انجام / موعد) و مرتب‌سازی
- اگر نسخهٔ قبلی را قبلاً دیپلوی کرده‌اید، ستون‌های جدید خودکار به همان جدول اضافه می‌شوند و کارهای قبلی حفظ می‌شوند.
